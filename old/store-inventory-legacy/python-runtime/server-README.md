# 本地数据库服务（SQLite）

把原先"只存在浏览器里"的进销存数据，落到磁盘上的一个文件 `data/餐厅系统.db`，
同时保留浏览器 localStorage 作为离线兜底。

## 1. 怎么用

1. 双击项目根目录的 **启动系统.bat**（保持窗口开着 = 服务运行中）；已默认 `open_browser: true`，会自动打开浏览器到 `http://127.0.0.1:8765/`
   - 新机器/新环境可先双击根目录 **`自检.bat`** 做环境检查（Python 版本、核心文件、数据库、端口占用）
2. 看页面右上角的状态灯：
   - 🟢 **已同步 · revN** —— 数据已写入数据库
   - 🟡 正在同步… —— 传输中
   - ⚪ **离线模式** —— 服务没开或没连上，数据暂存在浏览器，下次启动自动补传
   - 🔴 已同步但有冲突 —— 两台机器改了同一条记录，见设置页提示

关掉 bat 窗口 = 停止服务，页面自动转入离线模式，不会丢数据。

## 2. 数据在文件里

| 文件 | 说明 |
|---|---|
| `data/餐厅系统.db` | 主数据库（SQLite），拷走它就等于拷走全部业务数据 |
| `data/backups/餐厅系统_YYYYMMDD_HHMM_*.db` | 每次启动服务产生的整库冷备份，可直接复制使用 |
| 库内 `snapshots` 表 | 每次同步自动留一版，设置页可一键回滚 |

## 3. 换电脑 / 店与家

> **完整的新机器部署流程（含打包清单、排除项、环境自检、常见故障）见 [`docs/移植说明.md`](../docs/移植说明.md)。**
> 速查：装 Python 3.8+ → 拷整套文件夹（尤其 `data/餐厅系统.db`）→ 双击根目录 `自检.bat` → 双击 `启动系统.bat`。

**方式 A：拷数据库（一次性搬家）**
把 `data/餐厅系统.db` 拷到另一台机器的同样位置，起服务即可。
新机器首次打开页面时，`startSync()` 会识别"本机从未有过数据"，**自动以数据库为准**落地，
不会把 HTML 内置的示例数据合并进真实库（详见 `docs/modules/数据同步与备份.md` 决策7）。

**方式 B：网盘同步（推荐长期用）**
把 `config.json` 里的 `db_path` 指向 OneDrive / 坚果云同步目录里的 db 文件，
两台机器的 `machine_id` 设成不同值（`SHOP` / `HOME`）。
每次同步会自动做三向合并，**两端的改动都会保留**，不会互相覆盖。
注意：同一时刻尽量只在一台机器上录入，避免网盘产生冲突副本。

**方式 C：局域网直连（同一家店多台机器）**
在常开的那台上 `python server\app.py --host 0.0.0.0`，
另一台在页面「设置 → 服务地址」填 `http://192.168.x.x:8765`。

## 4. 合并规则（两台机器各录各的，怎么合）

按记录 id 逐条比较"上次同步版本 / 本机 / 数据库"三份：

| 情况 | 结果 |
|---|---|
| 只有一端改了 | 用改过的那端 |
| 两端都改了 | 比记录更新时间，新的胜出；时间相同取数据库版本并标记冲突 |
| 一端删、另一端没动 | 删除生效 |
| 一端删、另一端改过 | 保留改过的那条（防止误删），并标记冲突 |
| 两端各自新增 | 都保留（id 不同即视为不同记录） |

库存数量与移动加权均价是**派生值**，落地后一律调用 `rebuildStock()` 重放重算，
不会直接采信任何一端，保证计价核心不受同步影响。

## 5. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 服务与库状态 |
| GET | `/api/rev` | 只取版本号（心跳，判断是否需要合并） |
| GET | `/api/db` | 取整库 |
| PUT | `/api/db` | `{rev, data, machine}` 整库写；rev 不匹配返回 409；`force:true` 强制覆盖 |
| POST | `/api/sync` | `{baseRev, data, machine}` 三向合并后写入 |
| GET | `/api/snapshots` | 快照列表 |
| POST | `/api/snapshot` | 手动打快照 |
| POST | `/api/rollback` | `{rev}` 回滚 |

## 6. 命令行参数

```bat
python server\app.py --port 8765 --host 127.0.0.1 --db data\餐厅系统.db --machine SHOP
```

`config.json` 里可改默认端口、数据库路径、本机标识、快照保留天数。

## 7. 常见问题

**Q：状态灯一直是灰的"离线模式"？**
先看 bat 窗口有没有报错；再确认页面「设置 → 服务地址」是 `http://127.0.0.1:8765`。
从 `file://` 双击打开的页面靠 CORS 访问本服务，属正常设计。

**Q：清空浏览器缓存会丢数据吗？**
不会。数据已落盘到 `data/餐厅系统.db`，重新打开页面会自动从数据库拉回来。

**Q：想回到纯浏览器模式？**
关掉服务即可，页面照常能录入，只是数据只在本机浏览器，下次开服务会自动补传。

**Q：合并出现冲突怎么办？**
状态灯变红并显示条数。设置页可查看快照、回滚到合并前的版本；
被判负的一方记录在返回的 conflicts 里，必要时从快照找回。
