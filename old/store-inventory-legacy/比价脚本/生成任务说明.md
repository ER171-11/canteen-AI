# 一键比价脚本 · 使用说明

> 目标：把系统里 74 种原料的行情，用脚本批量抓到 1688 上，再一键导入系统自动比价。
> **原有手工比价功能（去比价 / 录入报价 / 报价记录）完全保留、互不影响。**
>
> 本目录提供**两个抓价引擎**，任选其一即可，产出的 `比价结果.json` 完全相同：
>
> | 引擎 | 脚本 | 双击入口 | 适用场景 |
> |---|---|---|---|
> | 接口引擎 | `fetch_quotes.py` | `运行比价.bat` | 有 onebound 等聚合接口 Key，最快 |
> | **浏览器引擎** | `fetch_quotes_selenium.py` | `运行比价-网页版.bat` | 开放平台接口不可用 / 数据不符合预期 |

---

## 一、整体流程（3 步）

```
① 系统「外接比价」页 ──点击【生成本次比价任务】──►  待比价任务_YYYY-MM-DD.json
                                                        │
                                                        ▼
② 把 JSON 放进 比价脚本/ 目录 ──双击【运行比价-网页版.bat】──►  比价结果.json  +  比价结果.xlsx
   （或双击【运行比价.bat】走接口引擎）
                                                        │
                                                        ▼
③ 系统「外接比价」页 ──点击【导入比价结果】选比价结果.json──►  报价自动入账、表格立即显示差价
```

## 二、浏览器引擎（推荐，当前主用）

用 Selenium 驱动真实 Chrome / Edge 打开 `s.1688.com` 搜索页抓价。

### 2.1 环境准备

1. **本机要有 Chrome 或 Edge**
   - 有 Chrome 就默认用 Chrome；
   - 没装 Chrome 会自动回落 Edge，也可显式指定：
     ```bat
     python fetch_quotes_selenium.py --browser edge
     python fetch_quotes_selenium.py --binary "D:\Chrome\Application\chrome.exe"
     ```
2. **装依赖（只需一次）**：双击 `运行比价-网页版.bat` 会自动检测并安装；也可手动
   ```bat
   pip install -r requirements.txt
   ```

### 2.2 首次运行：登录一次

双击 `运行比价-网页版.bat`，会自动弹出一个浏览器窗口：

1. 若检测到**未登录 1688**，脚本会暂停并提示你**在浏览器里扫码登录**（推荐用手机 1688/淘宝 App 扫码）；
2. 登录成功后**不用做任何操作**，脚本自动继续抓价；
3. 登录信息保存在本目录的 `chrome_profile/` 里，**以后不用再登**。

> ⚠️ `chrome_profile/` 里含有你的登录凭据，**不要打包发给别人、不要提交到公开仓库**。想换账号，直接删掉这个目录再跑一次。

### 2.3 抓价节奏（重要）

- 每次浏览器操作之间等待 **2.5 秒**（`delay`，另带 ±0.35s 抖动，见 `config.json` 的 `selenium` 段）；
- 每页自动下滑 3 次触发懒加载；每 10 个原料自动保存一次中间结果；
- **不建议调快**：低于 1 秒极易触发风控（滑块/登录墙），反而抓不到数据。抓得慢就慢慢挂着跑。
- 遇到**滑块验证 / 登录墙**时，脚本会暂停并提示你**手动处理**，处理完自动继续（等待上限 `login_wait`，默认 300s）。

### 2.4 常用命令

```bat
python fetch_quotes_selenium.py                      :: 全量抓（自动找最新 待比价任务*.json）
python fetch_quotes_selenium.py --limit 3            :: 只抓前 3 种，先试跑（强烈建议第一次这么做）
python fetch_quotes_selenium.py --keyword 东古一品鲜   :: 只搜一个词，快速验证选择器是否有效
python fetch_quotes_selenium.py --delay 3.5          :: 放慢到 3.5 秒/次（被拦截时用）
python fetch_quotes_selenium.py --top-n 5            :: 每个原料取最便宜的 5 条
python fetch_quotes_selenium.py --browser edge       :: 用 Edge 内核
python fetch_quotes_selenium.py --dry-run            :: 不开浏览器，仅验证输出链路
```

### 2.5 抓不到数据怎么办

按顺序排查：

1. **看日志里有没有打印「命中卡片选择器 xxx」**
   - 有 → 说明选择器有效，结果为空是该关键词没搜到，换关键词重试；
   - 没有 → **1688 前端改版了**。打开 `fetch_quotes_selenium.py`，把顶部 `CARD_SEL` / `TITLE_SEL` / `PRICE_SEL` 里的选择器换成新版页面的（在浏览器里按 F12 → 元素选择器点一下商品卡片即可看到 class）。
2. **看 `debug/` 目录里有没有截图**（脚本在超时/空结果时会自动截图）
   - 截图显示登录页 → 删掉 `chrome_profile/` 重新登录；
   - 截图显示滑块 → 手动拖动滑块，或用 `--delay 4` 重跑。
3. **是不是无头模式** → `--headless` 很容易被 1688 拦截，去掉它。

## 三、接口引擎（可选，有 Key 时更快）

通过第三方聚合接口 **onebound（万邦）** 调用 1688 商品搜索，需要 key。

1. 打开 `config.json`，填写密钥：

```json
{
  "api_url": "https://api-gw.onebound.cn/1688/item_search",
  "api_key": "这里填你的 KEY",
  "api_secret": "这里填你的 SECRET",
  "sleep": 1.5,
  "retry": 2,
  "top_n": 3,
  "source": "1688(API)",
  "allow_conv_grab": false
}
```

2. 到 <https://www.onebound.cn/> 注册，把后台的 `key` / `secret` 填进 `api_key` / `api_secret`。
3. **密钥只存在本地这个文件里**，不会上传、不会写进网页。不要外发。

| 参数 | 含义 | 建议 |
|---|---|---|
| `page_size` | 每次请求返回条数 | 40 |
| `pages` | 每个关键词抓几页 | 1（翻页成倍消耗接口次数） |
| `sleep` | 每次请求间隔秒数 | 1.5，接口吃紧调到 3 |
| `retry` | 失败重试次数（指数退避） | 2 |
| `sort` | 排序方式 | `price` 按价格从低到高 |
| `top_n` | 每个原料保留最低的几条报价 | 3 |
| `keyword_suffix` | 给所有关键词追加的后缀 | 如 `"整箱"`，一般留空 |
| `allow_conv_grab` | 是否抓取「采购单位≠库存单位」的原料 | **默认 false（跳过）**，见下方口径说明 |

```bat
python fetch_quotes.py --limit 5    :: 只抓前 5 种，先试跑
python fetch_quotes.py --dry-run    :: 免密钥联调，生成示例结果不发网络请求
```

## 四、统一的输出与导入

两个引擎跑完都会在本目录产出：

- `比价结果.json` —— **给系统导入用**（系统只认这个文件）
- `比价结果.xlsx` —— 人看的比价表（商品标题、批发价、起订量、供应商、发货地、链接、折库存单价、与本店差价、差价率；折算与差价列为 Excel 公式）

**导入**：回系统「外接比价」页 → 点 **② 导入比价结果** → 选中 `比价结果.json` → 预览确认 → 报价追加进 `DB.quotes`，比价表立即刷新。

> ⚠️ **关于单位口径**：系统里采购价按「采购单位」录入（例如 1 件 = 12 瓶），导入时按换算率折算成库存单位成本。
> 若某原料的换算率 ≠ 1，1688 的报价到底是「1 件」还是「1 瓶」无法自动判断，为避免算错成本，脚本**默认跳过**这类原料。
> 确认口径无误后可把 `allow_conv_grab` 改为 `true` 强制抓取，但务必人工核对 Excel 里的「规格核对」列。

## 五、附：生成 1688「清单询价」材料（人工询价兜底）

如果不想跑脚本，也可以把任务清单转成 1688 买家工作台的清单询价模板，让 1688 的 AI 报价助理帮你问：

```bat
python make_quote_list.py
```

产出在**项目根目录** `询价清单/` 下：

- `询价清单_YYYY-MM-DD.xlsx` —— 按类目拆成多个工作表（干调类 / 蔬菜类 / 鲜肉类 / 水产类），「采购数量」列留空等你填（填 ≥1 的整数，留空=本次不询价），另有「全部汇总」和「使用说明」页
- `询价清单说明_YYYY-MM-DD.md` —— 操作流程与注意事项

用法：填好数量 → 保存 → 打开 1688 买家工作台 → **询报价 → 清单询价** → 上传该 xlsx。

## 六、常见问题

**Q1：报「缺少 selenium 依赖」**
→ 双击 `运行比价-网页版.bat` 会自动装；或手动 `pip install -r requirements.txt`。

**Q2：报「未找到 Chrome 浏览器」**
→ 用 `--browser edge` 走系统自带的 Edge；或 `--binary "路径\chrome.exe"` 指定内核。

**Q3：报错「config.json 里的 api_key / api_secret 为空」**
→ 那是**接口引擎**的报错。要么按第三节填密钥，要么改用浏览器引擎。

**Q4：报「未找到 待比价任务*.json」**
→ 先回系统点 ① 生成任务，把文件放进 `比价脚本/` 目录，或用 `--task 路径` 指定。

**Q5：某个原料抓不到结果 / 抓到的完全不相干**
→ 关键词命中率问题。打开导出的任务 JSON，把该原料的 `keyword` 改成更精准的词（如「李锦记叉烧酱 240g」→「李锦记 叉烧酱」），再重跑。

**Q6：导入后报价里出现重复**
→ 系统按「原料 + 来源 + 价格」去重。同一原料两次抓到的价格不同会各保留一条，属正常；价格相同的会跳过。两个引擎来源标签不同（`1688(网页)` / `1688(API)`），可并存对比。

**Q7：导入报「文件格式不正确」**
→ 确认选的是 `比价结果.json`（不是 `.xlsx`、也不是任务文件）。

**Q8：抓到的价格明显不对（页面是「1 瓶」但系统按「1 件」记）**
→ 这类原料换算率 ≠ 1，脚本默认跳过。若已强制抓取（`allow_conv_grab=true`），请在系统比价表里逐条核对，或在「报价记录」里删除该条。

**Q9：跑到一半关了窗口**
→ 中间结果每 10 个原料会自动写一次 `比价结果.json`，可先导入已有部分；再用 `--task` 指定同一任务重跑缺失的（已导入的会自动去重）。

**Q10：接口报 401/403/余额不足**
→ onebound 的 key 失效或次数用尽。改用浏览器引擎即可绕过。

## 七、安全与回档

- `config.json` 的 API 密钥、`chrome_profile/` 的登录凭据都只存在**本地**，**不要把这两个东西分享出去**。
- 导入是**追加**语义：只新增报价记录，不修改/删除任何既有报价、不动库存、不动配方。
- 误导入想撤销：到「外接比价」页 → 对应原料的「报价记录」→ 逐条「删」；或用导入前的 JSON 备份在设置页「导入JSON备份」整体回滚。
- 脚本不写系统数据文件，只产出 `比价结果.json` / `比价结果.xlsx`，删掉即可。
- 抓价请遵守平台规则：**不要**把 `delay` 调到 1 秒以下，**不要**尝试自动化绕过验证码。
