
**为什么建议 T6 之前先清 T8**：T6 引入的是**写类**功能（新建/编辑/作废），

## 4. 硬约束（不可违反）

**业务红线**
1. `rebuildStock` / `dishRecipeCost` / `calcSaleCost` / `seedDB` 只可调用，不可改写；`bff/store-node/{db,merge}.js` 有哈希基线，改动需重算且写明理由
2. 自动生成 ≠ 自动下单；预测 ≠ 下单；AI 不直接写库
3. 写回必经「确认 → `/api/actions` 队列 → 审批」，带 rev 乐观锁
4. 结算单是只读输出层，不写 DB；图片不落库；Key 仅 env
5. 后台禁止旁路写（直连 `/api/sync` / sqlite / `.db`）
6. **功能对等不可静默降级**（ARCHITECTURE 规则 5）：迁移以 FP 为单位，先建基线，四态标注，禁止以「页面存在/接口存在」充当完成

**流程红线**
7. 高风险改动先输出 `[EDIT_PLAN]` 等确认；每批工作完成输出 `[WORK_DIFF]`
8. 每完成一个 FP，更新 `docs/迁移基线/*.md` 状态；未标注行会被 CI R14 判失败
9. 平价测试全绿 ≠ 功能已迁移，两条门禁分别通过

## 5. 环境坑（本机 Windows）

| 坑 | 表现 | 规避 |
|---|---|---|
| `python3` 是 Microsoft Store 别名存根 | 带 stdin 调用静默失败，stdout/stderr 全空 | 统一走 `bff/lib/_python.js`（已修），或设 `PARITY_PYTHON` |
| 无 bash | `ci/redline_guard.sh`、`bff/test_contract.sh` 本地跑不了 | 用规范附录 B 的 PowerShell 等价命令 |
| Python 中文默认 GBK | 跨端中文变乱码 → 平价测试假失败 | 已强制 `PYTHONIOENCODING=utf-8` |
| `old/.../python-seed/{migrations,data}` 是 Git 符号链接 | Windows `core.symlinks=false` 落成文本文件 → `FileNotFoundError` | 已在 3 个 Python 脚本加 `_resolve_sql()` 回退 |
| 读取中文文件 | PowerShell `Get-Content` 不带编码会被拦 | 一律加 `-Encoding UTF8` |
